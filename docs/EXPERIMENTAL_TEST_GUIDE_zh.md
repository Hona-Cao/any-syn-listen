# Any Syn Listen 测试版使用说明（Windows）

> **本文件描述开发分支的实验功能。它们通过了模拟接口和桌面端打包检查，但尚未通过真人账号与 Windows 实机测试。**

## 安装

1. 打开本项目 GitHub → Actions → **Windows portable experimental build (no Codex)**。
2. 选择最新的**成功**运行记录，在运行详情页 **Artifacts** 区下载 `any-syn-listen-windows-x64-experimental`。下载后解压，运行里面的便携版 EXE。
3. 当前安装包没有商业代码签名，Windows 可能弹出 SmartScreen 安全提醒；请只从你自己的 GitHub Fork 的 Actions 页面获取，不要下载陌生人分享的同名软件。
4. 测试版使用独立的 `any-syn-listen` 软件标识与 `AnySynListenDatas` 数据目录，不会把 AnyListen 的账户/歌单数据库当成自己的数据库。请在正式测试前备份两端歌单。

## LX N Music 与 AnyListen WebDAV

1. 在安卓版 LX N Music 里确保 WebDAV 歌单同步已经工作，远程默认产生 `/LX_Music/playlists.json`。
2. 在测试版 Any Syn Listen 的「设置 → WebDAV 同步」填写和安卓端**相同**的 WebDAV 地址、账号、密码。
3. **LX N Music 镜像开关**单独打开，目录填 `/LX_Music/`。无需也不建议为了此功能修改 AnyListen 原有快照同步目录。
4. 等待或重启应用，检查左侧是否出现 `LX N · 试听列表`、`LX N · 我的收藏` 与其他 `LX N ·` 歌单。
5. 这是手机 → 电脑的单向镜像，不会写回安卓端，也不会覆盖桌面端原有的我喜欢。

## 网易云音乐

1. 在同一设置页点击「打开网易云官方登录页面」，在官方登录窗口完成手机号/扫码/安全验证。
2. 登录成功后，等待出现 `网易云 ·` 歌单及 `网易云 · 每日推荐`。
3. 后台低频尝试刷新凭据，但平台可能随时要求重新登录。原镜像不会因为登录过期被删除。
4. 桌面端优先使用操作系统安全存储。手动 Cookie 输入框是无安全存储时的备用手段，保存于普通设置文件，正式使用不推荐。

## QQ 音乐

1. 点击「打开 QQ 音乐官方登录窗口」。
2. 使用官方网页提供的 QQ/微信授权。授权成功后，测试版尝试捕获该网页登录态。
3. 读取成功则出现 `QQ 音乐 ·` 歌单，及可能出现 `QQ 音乐 · 我喜欢`。
4. QQ 音乐网页有多套登录态，当前捕获/续期仍需实机确认。若未出现歌单，请反馈登录窗口是否正常进入用户主页即可。

## 酷狗音乐

1. 点击「酷狗音乐扫码登录（原生接口）」。
2. 使用酷狗客户端扫描二维码并确认，窗口关闭后会按账号同步 `酷狗 ·` 歌单。
3. 对只含文件 hash 的歌曲，程序会尝试补齐 ID、名称、音质，避免覆盖为不可识别占位歌曲。
4. 酷狗协议是逆向 API，可能因账号、平台或接口调整而失效；需要真实账号回归测试。

## 音乐播放

**同步成功不代表自动拥有所有平台的音频播放权。** AnyListen 仍需相应在线音乐元数据/播放资源扩展；账户登录只是为了读取你自己的歌单与每日推荐，不会解锁 VIP 或绕过版权限制。可以先安装 AnyListen 官方 Online Metadata 扩展以解析音乐元数据。

## 隐私与报错反馈

- **不要发送** Cookie、MUSIC_U、musickey、酷狗 token、网页验证码、手机号码或完整含个人信息的网络日志。
- 只需告知「哪一个平台、点击了什么、显示了什么提示、有没有出现歌单、能否播放」，必要时提供已涂抹账号信息的截图。
- 不要同时把同一歌单在两端反复编辑；目前是只读单向镜像，没有双向三方合并。
- QQ/酷狗暂时是每次需要时用官方页面重新登录，尚未实现完整令牌自动续期。

## 当前自动化检查

- `Cloud music protocol unit tests (no Codex)`：全部使用模拟 HTTP，无需私人账号。
- `Desktop bundle smoke build (no Codex)`：检查桌面端 JS 入口、界面、预加载脚本是否成功生成。
- `Integration typechecks (no Codex)`：收集完整 TS/Svelte 的诊断。原上游仓库已有不少基础类型错误，因此该工作流是**继续执行的诊断任务**，绿色不等于无 TS 报错。
- `Windows portable experimental build (no Codex)`：生成适合下载的 Windows x64 EXE；**只有此任务成功并上传 Artifacts 才表示有可下载安装包**。
