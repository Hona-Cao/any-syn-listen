# 账号歌单同步 v0.3.4 · AnyListen 官方扩展

在官方 AnyListen 的 扩展管理 → 本地安装 中安装 releases/hona-account-sync_v0.3.4.alix。管理界面使用 AnyListen 的原生设置控件，不需要额外 EXE 或 127.0.0.1:38481 登录助手。

## WebDAV：平铺填写

扩展设置使用统一的 AnyListen 原生排版：上方是「音乐账号」，下方是「LX N · WebDAV」与四个平铺输入框。输入 WebDAV 地址、用户名、应用密码、歌单目录，点击「保存设置」。下次可直接修改。点击「断开连接」不会删除原歌单。

应用密码保存后界面会自动显示遮蔽字符，原始值保存在扩展私有数据存储。注意：官方扩展表单目前不支持密码型输入框，输入期间仍会以明文显示，并经 AnyListen 设置系统处理。录屏和共享电脑请勿输入敏感密码。读取 /LX_Music/playlists.json 为只读，不回写安卓端。

## 音乐平台

- 网易云：点击「网易云登录」，通过插件生成的网易云官方二维码页面扫码确认。插件会轮询授权状态并自动接收网易云返回的 MUSIC_U 登录凭据，**不再需要用户手动找 Cookie**。若网易云风控阻止授权，可通过命令面板使用手动导入作为备用方式。
- QQ音乐：使用腾讯官方微信二维码，扫码后在后台检查结果，登录状态会显示等待扫码、已扫码待确认和验证账号中；90 秒未完成或状态查询失败会退出并报错。支持导入网页版 Cookie，账号自建、收藏歌单、我喜欢和推荐接口按可用性读取。
- 酷狗：手机号验证码登录；登录请求补齐 KugouMusicApi 的专用请求头，错误会显示安全的状态码。另可导入已有会话字段 userid、token、mid。账号歌单和每日推荐取决于服务端接口是否返回内容。

平台列表会使用网易云·、QQ音乐·、酷狗·等前缀。上述为预期功能；真实用户的私有歌单和每日推荐仍需要实机验证，不能保证每个账号、网络或风控条件下都有效。

## 数据与安全

Cookie 和 WebDAV 应用密码仅用于用户填写的音乐服务 / WebDAV 服务器，保存于本机当前用户的扩展私有存储，尚未实现操作系统钥匙串加密。输入密码时原生设置 UI 会短暂显示明文，且设置持久化由 AnyListen 负责。不要共享或公开备份扩展数据。不同电脑需要分别登录。

官方扩展仍没有通用浏览器 Cookie 读取能力，但网易云和 QQ 音乐可以通过各自的扫码授权接口直接换取会话，无需打开可读取 Cookie 的内置浏览器。AnyListen 目前也没有开放本地歌单写入接口，因此纯插件无法实现原版侧栏 Ctrl/Shift 批量删除和归档。

## 验证

使用 npm run build:extension、npm test 构建和测试，涵盖网易云扫码自动换取会话、取消登录、统一原生布局和模拟平台网络请求、WebDAV 平铺设置与密码遮蔽、真实官方扩展缺失 URL 全局对象、微信扫码模拟、QQ 我喜欢详情，以及酷狗 API 失败的安全诊断。无需调用 Codex。

## v0.3.4 界面调整

三个音乐平台使用统一登录按钮和状态标签，避免在设置页面暴露 Cookie 技术术语；WebDAV 保留一个简洁区块和四个等宽原生输入框。没有自制 CSS 或独立登录助手，字号与颜色由 AnyListen 当前主题决定。二维码真实授权与各平台私人歌单仍需实际账号验证。


## v0.3.4 登录问题修复
- QQ 音乐：纠正微信扫码状态映射，408 为等待扫码、404 为已扫待确认、405 为已确认；确认后立即交换 QQ 登录状态。空授权码会明确报错。
- 网易云：二维码申请与轮询改为实际验证过的公开 GET 接口 /api/login/qrcode/unikey 与 /api/login/qrcode/client/login，不再用此前不可靠的 WEAPI POST 请求二维码。
- 酷狗：短信验证码得到 20006 时，不认为是用户输错验证码；提供酷狗客户端扫码授权的备用方式。匿名测试确认扫码申请和状态查询正常，真实账号扫码换票仍待实测。
- 安装升级：GitHub Actions 固定使用仓库 Secrets 中的发布签名密钥，缺少密钥就停止，不再为每个版本随机生成签名。
