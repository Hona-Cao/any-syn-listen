# AnyListen 账号歌单同步扩展 · v0.3.0

这是安装到 **官方 AnyListen** 中的真正 .alix 扩展。无需修改播放器、不需要额外 Electron 程序、不需要在本机运行 127.0.0.1:38481 服务。

**安装：**打开「扩展管理 → 本地安装」，选择 hona-account-sync_v0.3.0.alix；管理界面在「设置 → 扩展设置 → 账号歌单同步」。已有 0.2.1 用户可通过本地安装升级，0.3.0 不会连接旧版助手，不必为它配置任何端口。

## 平台和登录

- 网易云音乐：AnyListen 原生手机号输入、短信验证码输入，直接向网易云接口登录；提供「网易云·我喜欢」「网易云·每日推荐」和用户歌单。
- QQ音乐：由扩展向腾讯获取微信授权二维码，使用 AnyListen 原生弹窗的「打开微信二维码」按钮在系统浏览器打开官方二维码；手机微信扫码后扩展主动查询腾讯扫码状态。提供「QQ音乐·我喜欢」「QQ音乐·每日推荐」和账号歌单。
- 酷狗音乐：原生手机号与短信验证码输入，扩展直接调用酷狗接口；提供「酷狗·我喜欢」「酷狗·每日推荐」和账号歌单。
- LX N Music：扩展使用直接 HTTPS WebDAV GET 读取 /LX_Music/playlists.json，兼容源客户端的歌单格式；不会写回安卓端。

**所有账号登录、歌单读取和 WebDAV 同步都使用 AnyListen 已开放的扩展网络接口**，不绑定特定电脑、Windows 版本或作者的本地调试端口。相应平台接口并非官方稳定开放 API；平台变更、限制或账号安全认证可能仍造成登录失败。

## 当前 AnyListen API 能力限制

AnyListen 上游当前没有在扩展运行时开放 musicList，因此不能由独立扩展自动新增、批量删除所有原生左侧歌单，亦不能替代原生侧栏 Ctrl/Shift 多选。0.3.0 利用公开的 registerResourceAction 将四种账号歌单注册成在线资源，可在 AnyListen 中手动添加并使用原生在线歌单自动刷新。

## 凭据存储说明

纯扩展没有访问系统钥匙串 / Electron safeStorage 的官方 API。**登录状态保存在 AnyListen 当前用户的扩展专属数据目录中，未使用系统钥匙串加密**；任何能访问你系统用户配置文件的人都有可能读取凭据。不要将扩展数据目录上传网盘、与他人共享或作为公开日志提交。启用系统磁盘加密、限制本机用户目录权限，并在其他电脑上重新登录。

插件不存储手机号、验证码或账号密码，只保留平台返回的会话凭据；WebDAV 需要保存授权账号和应用密码以便后续自动同步。不同电脑各自独立保存凭据，登录状态不会自动跨电脑迁移。

**离线或平台 API 故障不会删除已有歌单缓存。** LX N WebDAV 只读，不碰原应用同步快照。音乐播放仍需要相应的合法播放资源插件；导入歌单不意味着绕过 VIP 或版权限制。

## 开发验证

执行 npm ci、npm run build:extension、npm test。

官方 @any-listen/extension-kit 对 .alix 包签名。自动测试包含无助手运行、登录流程和 WebDAV 的模拟网络响应。公开微信授权页面已验证能够返回二维码 ID；**真正的扫码认证、三个平台私有歌单与每日推荐仍需要使用真实账号验证**，不能将模拟测试冒充生产验证。

## 历史版本

- v0.2.1 依赖用户本机预先安装的登录助手，其他电脑只安装 .alix 会出现 connect ECONNREFUSED 127.0.0.1:38481。
- v0.3.0 完全移除此依赖，所有功能直接通过扩展官方接口实现，旧助手不再需要用于本扩展。
