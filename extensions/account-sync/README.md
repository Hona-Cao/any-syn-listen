# 账号歌单同步 v0.3.2 · AnyListen 官方扩展

在官方 AnyListen 的 扩展管理 → 本地安装 中安装 releases/hona-account-sync_v0.3.2.alix。管理界面使用 AnyListen 的原生设置控件，不需要额外 EXE 或 127.0.0.1:38481 登录助手。

## WebDAV：平铺填写

扩展设置中直接填写 WebDAV 地址、用户名、应用密码、歌单目录，点击「保存连接」。下次可直接修改。点击「断开连接」不会删除原歌单。

应用密码保存后界面会自动显示遮蔽字符，原始值保存在扩展私有数据存储。注意：官方扩展表单目前不支持密码型输入框，输入期间仍会以明文显示，并经 AnyListen 设置系统处理。录屏和共享电脑请勿输入敏感密码。读取 /LX_Music/playlists.json 为只读，不回写安卓端。

## 音乐平台

- 网易云：通过「网易云登录」打开官方网站。完成网页授权后，需要由用户明确导入自己的 MUSIC_U Cookie；官方纯插件目前无法自动读取浏览器 HttpOnly Cookie。容易报错的短信接口不再作为首选。
- QQ音乐：使用腾讯官方微信二维码，扫码后在后台检查结果，登录状态会显示等待扫码、已扫码待确认和验证账号中；90 秒未完成或状态查询失败会退出并报错。支持导入网页版 Cookie，账号自建、收藏歌单、我喜欢和推荐接口按可用性读取。
- 酷狗：手机号验证码登录；登录请求补齐 KugouMusicApi 的专用请求头，错误会显示安全的状态码。另可导入已有会话字段 userid、token、mid。账号歌单和每日推荐取决于服务端接口是否返回内容。

平台列表会使用网易云·、QQ音乐·、酷狗·等前缀。上述为预期功能；真实用户的私有歌单和每日推荐仍需要实机验证，不能保证每个账号、网络或风控条件下都有效。

## 数据与安全

Cookie 和 WebDAV 应用密码仅用于用户填写的音乐服务 / WebDAV 服务器，保存于本机当前用户的扩展私有存储，尚未实现操作系统钥匙串加密。输入密码时原生设置 UI 会短暂显示明文，且设置持久化由 AnyListen 负责。不要共享或公开备份扩展数据。不同电脑需要分别登录。

官方插件运行时尚不提供浏览器 Cookie 读取、可取 Cookie 的官方网页登录窗口、本地歌单写入接口；因此不能实现真正自动抓取网页登录状态或官方版侧栏 Ctrl/Shift 批量删除和归档。

## 验证

使用 npm run build:extension、npm test 构建和测试，涵盖模拟平台网络请求、WebDAV 平铺设置与密码遮蔽、真实官方扩展缺失 URL 全局对象、微信扫码模拟、QQ 我喜欢详情，以及酷狗 API 失败的安全诊断。无需调用 Codex。
