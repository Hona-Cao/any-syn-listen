# AnyListen 账号歌单同步扩展 0.1.0

适用于支持扩展接口 1.4.0 的 AnyListen。扩展只使用公开的 `require("any-listen")` API，不修改播放器数据库文件或安装目录。

## 安装与使用

1. 打开 **AnyListen 账号助手**。
2. 在原版 AnyListen 的扩展管理中导入 `hona-account-sync_v0.1.0.alix`，允许网络和歌单权限。
3. 在播放器顶部搜索框输入 `> 连接账号助手`，选择该命令，输入助手显示的 8 位连接码。
4. 在助手登录网易云、酷狗，或通过腾讯官方窗口登录 QQ 音乐。账号助手运行期间，歌单自动进入播放器。
5. 助手的“歌单”页支持 Ctrl 多选、Shift 连选、Ctrl+A 全选、归档、删除。“归档与回收站”中可以恢复。

归档/删除只处理本地普通和在线歌单，不删除平台账号歌单、WebDAV 文件或本地音乐文件。删除前保存本地恢复快照；同步来源会暂停，避免自动重新导入。系统内置列表、本地目录列表和远程文件目录不在批量删除范围内。

账号登录、Ctrl/Shift 管理页在**独立账号助手**，不是注入播放器侧栏。原版目前没有网页授权窗口和自定义界面 API，因此这是“原生扩展 + 独立助手”，不是假称单个扩展拥有不存在的权限。以后音乐平台接口的修补发生在助手，不需要重编整个 AnyListen；如上游废弃扩展 API，扩展本身仍可能需要更新。

首次迁移需要在助手重新登录一次。旧测试版账号文件保留原样，不跨应用破解加密凭据。使用旧测试版连接扩展前，请关闭其内置平台/WebDAV同步；否则旧实现不认识扩展的归档排除规则。原版没有这个冲突。

## 已修复和限制

- 网易云验证码改用 `/weapi/sms/captcha/sent`，旧路径缺少 `sms/`，会返回 404。
- 酷狗接受 `listid=0`，保留自建/收藏歌单的 `type`，以完整目录版本请求，日推与单个歌单失败隔离，兼容数组响应。
- QQ 使用 QQ 音乐域的完整会话和 music UIN，保留官方 QQ/微信授权窗口；不伪造短信接口。不同账号的 QQ 扫码结果仍需实测。
- 推荐由平台账号服务生成；没有冒充平台推荐的本地随机列表，也没有自动回写 AnyListen 的喜欢/不喜欢。
- 扩展不提供音频解锁/播放地址；播放器仍使用用户合法可用的资源扩展。
- 所有新平台解析均有模拟测试，**不能代替真实账号登录与同步验证**。没有取得你的新助手登录态时，不会宣称酷狗日推实测成功。

## 构建

```sh
npm ci
npm run build:helper
node scripts/signing-key.mjs
npm run build:extension
npm test
```

`signing-key.mjs` 仅在本地缺少 `.env` 时生成签名密钥。保留该文件供以后更新签名使用，**不要提交或分享私钥**。CI 使用临时测试签名，不用于替换本地发布签名。

开发调试助手：`node_modules/.bin/electron helper-dist`。Windows 的发布目录由 `node scripts/package-windows.mjs` 生成；它使用独立 Electron 运行时，无需重新打包 AnyListen。助手监听 `127.0.0.1:38481`，使用一次性连接码和独立令牌；不对外网监听，不设置系统开机启动。
